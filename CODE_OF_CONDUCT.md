# Code of Conduct

This project aims to maintain a technical, respectful, and collaborative environment.

Participants are expected to:
- discuss ideas and evidence rather than attack people;
- give actionable technical feedback;
- disclose conflicts of interest when relevant;
- avoid publishing another person's secrets, personal data, or private vulnerability details;
- respect responsible-disclosure requests.

Harassment, threats, discriminatory abuse, deliberate doxxing, and malicious disclosure of sensitive security information are not acceptable.

Maintainers may edit, hide, or remove content and restrict participation when necessary to protect contributors or the project.
